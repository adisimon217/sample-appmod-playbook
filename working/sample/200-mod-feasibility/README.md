# Phase 200 — Modernization Feasibility

Analyze the Phase 100 inventory to classify workloads, score complexity, assess tool eligibility, and produce a prioritized wave plan.

## How to Run

Set `DEMO` and run the prompt. Analysis rules, scoring, and output format are in `feasibility-analysis.md`.

```
Read the inventory at #File:working/DEMO/100-data-collection/DEMO-App-Inventory.xlsx
(all sheets — Applications and Databases).

Then read #File:framework/200-Mod-Feasibility/feasibility-analysis.md and execute all four steps.

Save as working/DEMO/200-mod-feasibility/DEMO-Feasibility-Assessment.md.
```

## Output

```
working/DEMO/200-mod-feasibility/
  DEMO-Feasibility-Assessment.md
```

See [sample-output/analysis-output.md](../../../framework/200-Mod-Feasibility/sample-output/analysis-output.md) for an example.

Review the output, then proceed to [Phase 300](../300-detailed-assessment/README.md) for the apps selected for modernization.
